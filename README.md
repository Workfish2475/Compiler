## Overview


This project is a compiler implemented in C, utilizing Flex and Bison for lexical analysis and parsing. It translates source code into assembly language.

## Features

- Lexical analysis using Flex
- Parsing using Bison
- Abstract Syntax Tree (AST) construction
- Symbol table management
- Assembly code generation

## Getting Started


### Prerequisites

- C compiler (e.g., GCC)
- Flex
- Bison

## Usage

- Compile the program using the command `make`
- Run the program on a target C file like `./compiler input_file.c`
